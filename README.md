# Cars Dealership - Full-Stack Capstone Project

Este repositorio contiene el código fuente para el proyecto final del curso Full-Stack. La aplicación permite a los usuarios visualizar concesionarios de automóviles por estado, ver detalles específicos y dejar reseñas sobre sus experiencias.

## Detalles del Proyecto
* **Nombre de la Aplicación:** Cars Dealership
* **Tecnologías:** Django (Backend), React (Frontend), SQLite/PostgreSQL
